# Инструкция по добавлению поддержки сохранения порядка

## Проблема
Порядок элементов (треков, альбомов, артистов) не сохраняется после изменения.

## Решение
Нужно добавить поле `custom_order` в таблицы Supabase.

### Способ 1: Через SQL Editor в Supabase (Рекомендуется)

1. Откройте ваш проект Supabase в браузере
2. Перейдите в **SQL Editor** (слева в меню)
3. Нажмите **New Query** (или **+ New**)
4. Скопируйте содержимое файла **MIGRATION_custom_order.sql**
5. Вставьте в редактор
6. Нажмите **Run** (или Ctrl+Enter)

### Способ 2: Через pgAdmin или другой SQL клиент

Выполните все запросы из файла **MIGRATION_custom_order.sql** против вашей БД Supabase.

### Что произойдет после миграции

- Добавятся новые столбцы `custom_order` в таблицы `tracks`, `albums`, `artists`
- Все существующие записи получат значение `0` для `custom_order`
- Создадутся индексы для быстрой сортировки

## Проверка наличия поля custom_order

Чтобы убедиться, что поле добавлено:

1. Откройте Supabase
2. Перейдите в **Table Editor**
3. Выберите таблицу **tracks** (или **albums**, **artists**)
4. Должно быть поле **custom_order** типа INTEGER

Если поля нет - выполните SQL запросы еще раз!

## Проверка RLS политик

Если сохранение всё равно не работает, проверьте RLS политики:

1. Откройте Supabase
2. Перейдите в **Authentication** → **Policies**
3. Для каждой таблицы (tracks, albums, artists) проверьте что есть политика **UPDATE**
4. Политика должна позволять пользователю обновлять свои записи (WHERE user_id = auth.uid())

### Пример правильной политики для UPDATE:

```sql
CREATE POLICY "Users can update their own records"
ON tracks
FOR UPDATE
USING (auth.uid() = user_id)
WITH CHECK (auth.uid() = user_id);
```

## Отладка в браузере

1. Откройте браузер (Chrome/Firefox)
2. Нажмите **F12** чтобы открыть консоль разработчика
3. Перейдите на вкладку **Console**
4. Попробуйте изменить порядок и сохранить
5. В консоли должны быть логи вида:
   - "Загружаю данные..."
   - "Тип таблицы: tracks" (или albums/artists)
   - "✅ Успешно сохранено <id> с порядком X"
   - "❌ Ошибка при сохранении <id>: ..."

Если видите ошибки - скопируйте их полностью и проверьте:
- Есть ли поле custom_order в таблице?
- Есть ли RLS политика для UPDATE?
- Вы ли вошли в свой аккаунт?

## После миграции

После выполнения SQL запросов порядок элементов будет сохраняться корректно:
- Когда вы меняете порядок элементов через кнопку "↕️ Изменить порядок"
- Порядок сохраняется в базе данных
- При перезагрузке страницы порядок восстанавливается

## Проверка корректности

После миграции попробуйте:
1. Перейти на страницу с альбомами/артистами
2. Выбрать сортировку "Оценка ↓" или "Оценка ↑"
3. Нажать кнопку "↕️ Изменить порядок"
4. Перетащить элемент в новое место
5. Нажать "Сохранить порядок"
6. Проверить консоль (F12) на наличие ошибок
7. Перезагрузить страницу (F5)
8. Порядок должен остаться тем же

Если порядок не сохраняется:
- Проверьте консоль на ошибки
- Проверьте наличие поля custom_order в базе
- Проверьте RLS политики
- Убедитесь что вы вошли в свой аккаунт
