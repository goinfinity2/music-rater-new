# Инструкция по добавлению поддержки сохранения порядка

## Проблема
Порядок элементов (треков, альбомов, артистов) не сохраняется после изменения.

## Решение
Нужно добавить поле `custom_order` в таблицы Supabase.

### Способ 1: Через SQL Editor в Supabase (Рекомендуется)

1. Откройте ваш проект Supabase в браузере
2. Перейдите в **SQL Editor** (слева в меню)
3. Нажмите **New Query** (или **+ New**)
4. Скопируйте содержимое файла **MIGRATION_custom_order.sql**
5. Вставьте в редактор
6. Нажмите **Run** (или Ctrl+Enter)

### Способ 2: Через pgAdmin или другой SQL клиент

Выполните все запросы из файла **MIGRATION_custom_order.sql** против вашей БД Supabase.

### Что произойдет после миграции

- Добавятся новые столбцы `custom_order` в таблицы `tracks`, `albums`, `artists`
- Все существующие записи получат значение `0` для `custom_order`
- Создадутся индексы для быстрой сортировки

### После миграции

После выполнения SQL запросов порядок элементов будет сохраняться корректно:
- Когда вы меняете порядок элементов через кнопку "↕️ Изменить порядок"
- Порядок сохраняется в базе данных
- При перезагрузке страницы порядок восстанавливается

## Проверка
После миграции попробуйте:
1. Перейти на страницу с альбомами/артистами
2. Выбрать сортировку "Оценка ↓" или "Оценка ↑"
3. Нажать кнопку "↕️ Изменить порядок"
4. Перетащить элемент в новое место
5. Нажать "Сохранить порядок"
6. Перезагрузить страницу (F5)
7. Порядок должен остаться тем же
